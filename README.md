# Carnet Sèche

Appli de suivi de musculation et de sèche, à ouvrir sur téléphone.

- 4 séances : Dos / Biceps, Pecs / Triceps, Épaules / Trapèzes / Abdos, Jambes
- Minuteur de repos, progression des charges, fiches techniques animées
- XP, niveaux, badges et quête de la semaine
- Journal des repas, objectif calorique et suivi de la masse grasse

Les données restent sur le téléphone de chaque personne (pensez à faire une sauvegarde depuis l'onglet Progrès).

Pour l'installer sur iPhone : ouvrir le lien dans Safari, bouton Partager, puis « Sur l'écran d'accueil ».
